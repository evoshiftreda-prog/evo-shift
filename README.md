# Evo Shift
**Premium Luxury Creative Agency Website**

## Setup
Upload your files to the following folders:
- `images/` — agency logo (evo-shift-logo.png) and other images
- `videos/` — portfolio videos (.mp4 files, auto-loaded)
- `logos/` — brand logos (.png/.jpg/.svg, auto-loaded)

## Live Site
Enable GitHub Pages in repository Settings → Pages → Source: main branch, / (root)

Your site will be live at: https://evoshiftreda-prog.github.io/evo-shift/
